# 📄 42 DİL Belge Oluşturma Araçları

Profesyonel belgelerinizi kolayca oluşturmak için geliştirilmiş web tabanlı araç seti.

## 🎯 Özellikler

### 1. 📋 Yeminli Tercüme Şablonu Oluşturucu
- Resmi tercüme belgesi formatı
- Özelleştirilebilir tüm alanlar
- Tercüman bilgileri ve kaşe alanı
- Farklı belge türleri için şablonlar (Kimlik, Pasaport, Diploma vb.)

### 2. 👤 CV/Özgeçmiş Oluşturucu
- Modern ve profesyonel tasarım
- Fotoğraf yükleme desteği
- İş deneyimi ve eğitim bölümleri
- Yetenek listesi
- Anında önizleme

### 3. 🏆 Sertifika Oluşturucu
- 3 farklı tasarım seçeneği:
  - Modern (Gradient tasarım)
  - Klasik (Altın çerçeveli)
  - Minimalist
- Başarı, katılım, takdir sertifikaları
- Özel logo ve metin ekleme
- Çift imza alanı

## 🚀 Kullanım

1. `index.html` dosyasını bir web tarayıcısında açın
2. Kullanmak istediğiniz aracı seçin
3. Formu doldurun
4. Gerçek zamanlı önizlemeyi görün
5. PDF veya PNG olarak indirin

## 💻 Teknik Özellikler

- **Tamamen Çevrimdışı Çalışır**: Tüm işlemler tarayıcıda gerçekleşir
- **Veri Güvenliği**: Hiçbir veri sunucuya gönderilmez
- **Yüksek Kaliteli Çıktı**: PDF ve PNG formatlarında indirme
- **Duyarlı Tasarım**: Tüm ekran boyutlarına uyumlu
- **Gerçek Zamanlı Önizleme**: Değişiklikleri anında görün

## 📦 Gereksinimler

Modern bir web tarayıcısı (Chrome, Firefox, Safari, Edge)

## 📁 Proje Yapısı

```
/
├── index.html                      # Ana dashboard
├── translation-template/
│   └── index.html                  # Tercüme şablonu oluşturucu
├── cv-generator/
│   └── index.html                  # CV oluşturucu
├── certificate-generator/
│   └── index.html                  # Sertifika oluşturucu
└── assets/
    ├── css/
    └── js/
```

## 🎨 Özelleştirme

Her araç, kendi HTML dosyası içinde CSS stilleri ile tamamen özelleştirilebilir. Renkleri, yazı tiplerini ve düzeni ihtiyaçlarınıza göre değiştirebilirsiniz.

## 📝 Kullanılan Kütüphaneler

- **html2pdf.js**: PDF oluşturma
- **html2canvas**: Resim oluşturma

## 🔒 Gizlilik

Bu araçlar tamamen tarayıcınızda çalışır. Hiçbir veri harici sunuculara gönderilmez veya kaydedilmez. Tüm bilgileriniz cihazınızda kalır.
