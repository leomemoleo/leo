## 🛠️ Helper Functions (Yeni)

```php
// Settings alma
getSetting('site_name', 'Default')
getSettingBool('smtp_enabled')
getSettingInt('free_shipping_threshold', 500)

// Settings güncelleme
updateSetting('site_name', 'Yeni İsim')

// Kolaylık fonksiyonları
isMaintenanceMode()           // Bakım modu kontrolü
getCurrencySymbol()            // ₺
getCurrency()                  // TRY
isFeatureEnabled('wishlist')  // Özellik kontrolü
```

**Kullanım Örnekleri:**

```php
// Başlıkta
<title><?= getSetting('meta_title') ?></title>

// Ücretsiz kargo kontrolü
$threshold = getSettingInt('free_shipping_threshold', 500);
if ($cartTotal >= $threshold) {
    $shipping = 0; // Ücretsiz!
}

// Özellik kontrolü
if (isFeatureEnabled('loyalty')) {
    $points = $orderTotal * getSettingInt('loyalty_points_rate', 10);
}

// Bakım modu
if (isMaintenanceMode() && !isAdmin()) {
    show_maintenance_page();
    exit;
}
```
